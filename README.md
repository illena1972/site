# Recovered BioClean Workwear landing

Проект восстановлен из двух источников:

- прикрепленного `App.jsx` из чата "Создание лендинга для SaaS";
- опубликованных файлов с `https://bioclean.ru/`.

## Запуск

```powershell
npm install
npm run dev
```

## Сборка

```powershell
npm run build
```

Готовая сборка появляется в `dist`.
